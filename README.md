# Twitter Airline Sentiment Analysis

A simple, end-to-end social media analytics project: explore ~14,600 tweets
about six US airlines and build a sentiment classifier (negative / neutral /
positive) using TF-IDF + Logistic Regression.

## Project structure

```
.
├── data/
│   └── Tweets.csv              # raw dataset (see Data source below)
├── src/
│   ├── clean_text.py           # shared text-cleaning helper
│   ├── 01_eda.py                # exploratory data analysis + charts
│   └── 02_train_model.py        # TF-IDF + Logistic Regression classifier
├── output/                      # generated by the scripts (charts, metrics, sample predictions)
├── requirements.txt
└── README.md
```

## Data source

**Twitter US Airline Sentiment** dataset, originally released by
Crowdflower/Figure Eight on Kaggle:
https://www.kaggle.com/datasets/crowdflower/twitter-airline-sentiment

Tweets were scraped in February 2015 and contributors manually labelled each
tweet's sentiment (and, for negative tweets, the reason: late flight,
customer service issue, lost luggage, etc.) toward six US airlines: American,
Delta, Southwest, US Airways, United, and Virgin America.

`data/Tweets.csv` is a straight copy of the original file (14,640 rows, 15
columns) 
`data/Tweets.csv`.

## Usage

Run from the project root, in order:

```bash
python src/01_eda.py
python src/02_train_model.py
```

`01_eda.py` writes summary stats and four charts to `output/`.
`02_train_model.py` cleans the tweet text, trains the classifier, and writes
metrics, a confusion matrix, a feature-importance chart, and a sample of
predictions to `output/`.

## What each script does

**`01_eda.py`** — exploratory data analysis
- Overall sentiment distribution (62.7% negative, 21.2% neutral, 16.1% positive)
- Sentiment split by airline
- Top 10 reasons behind negative tweets (customer service, late flights, cancellations, ...)
- Tweet-length distribution by sentiment

**`02_train_model.py`** — sentiment classifier
- Cleans text: lowercases, strips URLs/@mentions/punctuation
- Splits 80/20 train/test (stratified by sentiment)
- Vectorises text with TF-IDF (unigrams + bigrams, top 5,000 terms)
- Trains a Logistic Regression classifier (`class_weight="balanced"` to
  offset the negative-tweet majority)
- Reports accuracy, precision/recall/F1 per class, a confusion matrix, and
  the words most associated with each sentiment class

## Results (this run)

| Metric | Value |
|---|---|
| Accuracy | **77.6%** |
| Negative F1 | 0.85 |
| Neutral F1 | 0.63 |
| Positive F1 | 0.72 |

Full report is in `output/model_metrics.txt` after running the scripts.
Negative tweets are easiest to classify (they're the majority class and use
distinctive complaint language); neutral tweets are hardest, since they
often overlap in wording with mild positive or negative tweets.

## Notes

- This is a teaching/portfolio-scale project — kept deliberately simple
  (one linear model, no deep learning, no external NLP libraries) so it
  is easy to read, run, and extend.
- Ideas for extending it: try a Naive Bayes or SVM baseline for comparison,
  add a word cloud per sentiment class, or fine-tune a small transformer
  (e.g. DistilBERT) and compare accuracy against this TF-IDF baseline.
